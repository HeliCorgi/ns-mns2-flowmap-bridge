## §1 — What the symmetry does to the geometric objects [D]

For `g ∈ SO(3)` and `g·u = u`: `u(gx) = g\,u(x)`; `ω(gx) = g\,ω(x)` (proper vector under rotations, `det g = +1`); `|ω|(gx) = |ω|(x)` (Γ-invariant scalar); `ξ(gx) = g\,ξ(x)`; `S(gx) = g\,S(x)\,gᵀ`; `α(gx) = α(x)`; `‖ω(t)‖_∞` unchanged. Three symmetry-forced facts:

- **(S-0) The origin is a zero.** `x = 0` is fixed by all of Γ, so `ω(0,t) = g\,ω(0,t)` for every `g`; A₄ fixes no nonzero vector (its 3-dimensional representation is irreducible) ⟹ **`ω(0,t) = 0` and `u(0,t) = 0` for all `t`.** The vorticity direction is undefined at the origin at every time, and every super-level set `{|ω| > λ}`, `λ > 0`, omits a neighbourhood of the origin — of **no a priori radius** (the radius is `≳ λ/‖∇ω(t)‖_∞`, a wall quantity).
- **(S-1) Direction pinning on the symmetry axes.** On the three 2-fold axes (`x = (x₁,0,0)` is fixed by `d₁`, etc.) `ω(x) = d₁ω(x)` ⟹ `ω₂(x) = ω₃(x) = 0`: `ω(x) ∥ e₁` wherever it is nonzero; on the four 3-fold axes (`x ∥ (±1,±1,±1)`, fixed by `C` or a conjugate) `ω(x) ∥ x`. Angles between distinct axes: 2-fold/2-fold `sin = 1`; 2-fold/3-fold `sin = √(2/3)`; 3-fold/3-fold `sin = 2√2/3`. **Hence for any two points `x, y` on two distinct symmetry axes with `|ω(x)|,|ω(y)| ≥ Λ`: `|sin∠(ω(x),ω(y))| ≥ √(2/3)`.**
- **(S-2) Super-level sets.** The magnitude set `Ω_s(λ) = {x: |ω(x,s)| > λ}` is Γ-invariant as a set. The six per-component sets `V^{i,±}_s = {x: ±ω_i(x,s) > λ}` are permuted: `V^{2,±} = C\,V^{1,±}`, `V^{3,±} = C²V^{1,±}`, `V^{1,−} = d₂V^{1,+}` (since `ω₁(d₂x) = −ω₁(x)`), and `V^{1,+}` is `d₁`-invariant. **All six are isometric copies of one set**, so every rotation-invariant geometric-measure property (1-D or 3-D sparseness at a scale, in Grujić's weak sense — existence of a direction) takes the same value on all six.

Nothing in (S-0)–(S-2) is a norm identity: unlike the Gram tensors of the T-DIR lineage, which Schur's lemma forces to scalars, `|ω|`, `ξ` and the level-set geometry are *pointwise* objects on which a finite group imposes only orbit relations and fixed-point constraints.

**What NS supplies unconditionally [D].** From `ω_t + u·∇ω = Sω + νΔω` (`Aω = ½ω×ω = 0`), on `{ω ≠ 0}` write `ω = |ω|ξ`; `ξ·∂_iξ = 0` gives `|∇ω|² = |∇|ω||² + |ω|²|∇ξ|²`, and `Δ(|ω|²/2) = |ω|Δ|ω| + |∇|ω||² = ω·Δω + |∇ω|²` gives `ω·Δω/|ω| = Δ|ω| − |ω||∇ξ|²`. Hence the anisotropic-diffusion form

> `D_t|ω| = α|ω| + νΔ|ω| − ν|ω||∇ξ|²`, `α = ξ·Sξ` (attribution to Constantin, SIAM Rev. 36 (1994) [H]; the derivation is [D]).

Integrating with the regularisation `φ_ε = (|ω|²+ε²)^{1/2}` (`D_tφ_ε = ω·Sω/φ_ε + νΔφ_ε − ν(|∇ω|² − |∇φ_ε|²)/φ_ε`, the last term `≥ 0`), letting `ε → 0` (Fatou on the non-negative term; at a non-degenerate zero of `ω` the limit `|ω||∇ξ|² ∼ 1/|x|` is integrable in 3-D), and using `α|ω| ≤ |S||ω|`, `∫|S||ω| ≤ ‖S‖₂‖ω‖₂ = ‖∇u‖₂²/√2` (div-free: `‖S‖₂² = ½‖∇u‖₂²`, `‖ω‖₂ = ‖∇u‖₂`), `∫₀^{T′}‖∇u‖₂² ≤ E₀/(2ν)`:
