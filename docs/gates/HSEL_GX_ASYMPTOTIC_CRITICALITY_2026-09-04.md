## §2 — The closure condition with constants [D]

Write `r_crit(k) = C_c(k)A_k^{-1/(k+2)}` (chain version; `C_c(k)` absorbs `(k!)^{1/(k+2)}`, `c^{k/(k+2)}`, any `2^{-k}`, and the `‖u₀‖₂`-factors of the GN conversion) and `r_apr(k) = C_a(k)‖u₀‖₂^{1/(k+5/2)}A_k^{-1/(k+5/2)}`. Then, exactly,

> **`r_apr(k) ≤ r_crit(k) ⟺ A_k^{\,\frac{1}{k+2}-\frac{1}{k+5/2}} ≤ \frac{C_c(k)}{C_a(k)}‖u₀‖₂^{-\frac{1}{k+5/2}} ⟺ A_k ≤ Θ(k) := \Big(\frac{C_c(k)}{C_a(k)}\Big)^{2(k+2)(k+5/2)}‖u₀‖₂^{-2(k+2)}`**  (the exponent gap is `1/(2(k+2)(k+5/2)) ∼ 1/(2k²)`).

Two facts fix the size of the two sides:

- **(F1) `A_k` is at least factorial.** By Cauchy estimates `A_k ≤ k!R_s^{-k}Λ` where `R_s` is the analyticity radius at `s`; conversely, for any admissible profile at the viscous scale (a Gaussian core of width `r_B`: `A_k ∼ Λ(2^kk!)^{1/2}r_B^{-k}`) `A_k` grows like `(k!)^{1/2}Λ^{1+k/2}`; and for every fixed `k`, `A_k → ∞` at a blow-up (`Λ ≤ C‖u‖₂^{θ}A_k^{1−θ}`). Hence `\ln A_k ≥ \tfrac{k}{2}\ln k + \tfrac{k}{2}\ln Λ + O(k)` on the relevant configurations.
- **(F2) `C_a(k)` can be taken bounded in `k`** [D, sketch]: in the duality lemma test against a band-limited bump `φ_r = ψ * 1_{B_{2r}}` (`\hat ψ` supported in `B_{C}`, `ψ ≥ 0`, fast decay): `‖D^kφ_r‖₂ ≤ (C/r)^kr^{3/2}·O(1)`, so `c* ≳ C^{-k}[λδ−(1−δ)]` and `C_a(k) = (c*)^{-1/(k+5/2)} ≤ C^{k/(k+5/2)}O(1) ≤ C`. (A compactly supported Gevrey bump would give `(k!)^{s/(k+5/2)} ∼ k^{s}`, also harmless; GX's `c*` is [V-extract: `k`-dependence not stated].)

**Case A — no chain hypotheses (GX Thm 3.5 as extracted).** The exponent gap is then `\frac{3}{2k+3}-\frac{2}{2k+3} = \frac{1}{2k+3}` (velocity form), so `Θ(k) = (2^{-k}c₀/C_a)^{2k+3}‖u₀‖₂^{-(2k+2)}` — at best *exponential* in `k` even if the `2^{-k}` were removed (`(c₀/C_a)^{2k+3}`), while `A_k` is *factorial* (F1). **Fails for every choice `k(t)`**, with or without the `2^{-k}`: `\ln Θ(k) ≤ (2k+3)\ln(c₀/C_a) − 2k\ln‖u₀‖₂ ≪ \tfrac{k}{2}\ln k ≤ \ln A_k` for large `k`, and for each fixed `k`, `A_k → ∞`. (The removal of the `2^{-k}` in this case is itself available [D, sketch]: use the level-0 analyticity radius `R_s ≳ 1/‖u(t)‖_∞` from the `L^∞` local theory and convert with a **`k`-uniform** GN constant — Taylor along a line from a maximum point with the 1-D Kolmogorov–Landau constants (`≤ π/2`) for the intermediate directional derivatives gives `‖u‖_∞ ≤ C‖u‖₂^{2k/(2k+3)}‖D^ku‖_∞^{3/(2k+3)}` with `C` independent of `k` — but it does not help: the exponent gap `1/(2k+3)` is too small.)

**Case B — ascending chain (GX Thm 3.8), exponent `1/(k+2)`, factorial gain.** Write `C_c(k) = (k!)^{1/(k+2)}c^{k/(k+2)}L(k)·(‖u₀‖₂\text{-factor})` with `L(k) ≤ 1` the per-level loss of the chain version (`L(k) = 2^{-k}` if the Thm 2.4 factor persists; unknown otherwise, [V-extract]). Since `(k!)^{1/(k+2)} ∼ k/e`,

> `\ln Θ(k) = 2(k+2)(k+5/2)\big[\ln k − 1 + \ln c₀ + \ln L(k) − \ln C_a\big] − 2(k+2)\ln‖u₀‖₂`.

- With `L(k) = 2^{-k}`: `\ln Θ(k) = −2k³\ln 2\,(1+o(1)) → −∞` super-exponentially; `Θ(k) < 1 ≤ A_k` for all `k ≥ k₁`; for `k < k₁`, `A_k → ∞` at blow-up exceeds `\max_{k<k₁}Θ(k) =: Θ_{max}(‖u₀‖₂)`. **No `k(t)` works.**
- With polynomial loss `L(k) = k^{-p}`: `\ln Θ(k) = 2(1−p)k²\ln k\,(1+o(1))`; for `p < 1` this beats `\ln A_k ≤ k\ln k + (k/2+1)\ln Λ + k\ln R_s^{-1}` as soon as `k ≳ \ln Λ/(4(1−p)\ln k)` — **then `k(t) ∼ \ln Λ_t/\ln\ln Λ_t → ∞` would force `r_apr ≤ r_crit` at the escape times**, and the level-k sparseness of any viscous-scale core would even *hold* (the `D^kω` super-level set of a Gaussian core is a family of shells of thickness `∼ r_B/\sqrt{k}`, 1-D sparse radially at the scale `r_crit(k) ∼ \sqrt{k}\,r_B` of the loss-free chain version — the fat-core obstruction of the twenty-fifth record dissolves at high `k`, which is the real content of "asymptotic criticality"); for `p ≥ 1` it fails.

**Time synchronization is not an obstruction.** The a priori sparseness holds at *every* time, so whichever level-k window `[t + 4^{-k-1}c^{-2}A_k^{-6/(2k+3)}, t + 4^{-k}c^{-2}A_k^{-6/(2k+3)}]` the criterion selects, the a priori statement is available inside it; the windows for different `k` need not be aligned because only one level is used at a time. (What *is* needed is that `t` be an escape time for the level-k norm and that the chain hypotheses hold at `t` — see chain selection.)

## §3 — The obstruction, reduced to one formula

> **Constant growth.** Closure at level `k` requires `\frac{C_c(k)}{C_a(k)} ≥ 1 + \frac{\ln A_k + 2(k+2)\ln‖u₀‖₂}{2(k+2)(k+5/2)}`, i.e. the level-k criterion constant must exceed the level-k a priori constant by a margin `∼ (\ln k + \ln Λ)/(4k)`. GX's machinery has `\frac{C_c(k)}{C_a(k)} ≤ 2^{-k}·O(k)`: the per-level loss `2^{-k}` (the `2^{2k}` in the level-k local existence time of Thm 2.4, i.e. the Leibniz-sum count in a level-k `L^∞` iteration) enters `Θ(k)` with exponent `2(k+2)(k+5/2)`, giving `Θ(k) ∼ 2^{-2k³} ≪ A_k`. The exponent match `(k+2)/(k+5/2) → 1` is therefore *irrelevant*: the gap closes only if the loss per derivative level is at most `k^{-1+ε}`, which no available level-k analyticity estimate provides (the loss-free level-0 route of Case A has the wrong exponent, and the factorial-gain chain route of Case B carries the loss).

**Residual if the loss were removed — chain selection.** The polynomial-loss chain version needs GX's ascending-chain hypothesis (3.8)–(3.9) at level `k(t) → ∞` *at the escape times*: monotonicity in `j ≤ k(t)` of `‖D^ju(t)‖^{1/(j+1)}/(c^{j/(j+1)}(j!)^{1/(j+1)})` together with the size condition (3.9) — a property of the solution's derivative sequence with no a priori justification (near a blow-up the normalised sequence is expected to increase once `R_s < 1/‖u‖_∞`-type thresholds are crossed, but nothing is proved, and the descending-chain regime of Thm 3.9 is the opposite case). In one line: *closure ⟸ [loss `L(k) ≥ k^{-1+ε}`] ∧ [chain (3.8)–(3.9) holds at level `k(t) ∼ \ln Λ_t/\ln\ln Λ_t` at escape times]*; the first conjunct is false in GX's machinery, the second is unproved.

## §4 — The R1 viscous-ball `L¹` check: NEGATIVE [D]

Let `Q(x₀,s) := Ω^{1/2}∫_{B_{cΩ^{-1/2}}(x₀)}|ω(s)|dx`, `Ω = ‖ω(s)‖_∞` (dimensionless). Two bounds hold at every time, independently of R1: the trivial `Q ≤ Ω^{1/2}·Ω·\tfrac{4π}{3}c³Ω^{-3/2} = \tfrac{4π}{3}c³` everywhere; and at a post-escape time, on the Harnack ball `B(x_{max}, (1−λ)Ω^{-1/2}/C₁)` (from `‖∇ω(s)‖_∞ ≤ C₁Λ_t^{3/2}`) `|ω| ≥ Ω/2`, so for `c ≤ (1−λ)/C₁`: `Q(x_{max},s) ≥ \tfrac{2π}{3}c³`. Hence `\sup_{x₀}Q ≤ ε` is **trivially true** for `c ≤ (3ε/4π)^{1/3}` and **false** for `(3ε/2π)^{1/3} < c ≤ (1−λ)/C₁` (and for larger `c` the normalised mass at the maximum is `≳ ((1−λ)/C₁)³` regardless). R1 (`∫_{B_r}|ω(T)| ≤ Cr³(νT)^{-3/2}‖ω₀‖₁ + ∫_{T−r²/ν}^TP + …`) adds at the viscous scale `r = cΩ^{-1/2}` only the bound `Q ≤ Ω^{1/2}[Cc³Ω^{-3/2}(νT)^{-3/2}‖ω₀‖₁ + m(c²/(νΩ)) + …]`, whose non-trivial part `Ω^{1/2}m(c²/(νΩ))` is `≳ ν c²·⟨E⟩_{window}/Ω^{1/2}`-type and, by the instantaneous Harnack bound `E ≳ Ω^{1/2}`, cannot fall below the trivial `O(c³)` level; the identity carries dimension-`L` information invisible at scale `Ω^{-1/2}`. **No time selection in the escape window changes this** (the Harnack ball exists at every post-escape time).

## §5 — VERDICT (addendum)

GX's asymptotic criticality **does not close by `k(t) → ∞`**: the obstruction is *constant growth* in the single formula of §3 (per-level loss `2^{-k}` raised to `∼2k²`), with *chain selection* as the residual if that loss were ever reduced to `k^{-1+ε}`; *time synchronization* is not an obstruction. The R1 check is negative. No Lean or numerics warranted.
