Goal: parametrize candidate blowup asymptotics by scaling exponents and overlay every kill

point-in-region test for future numerical runs. Claims are labeled:

- **[H] hard theorem** (published, load-bearing citation given);
- **[B] ansatz bookkeeping** (power-counting for the stated concentration ansatz — applies

- **[D] derived argument** (obtained here from [H] + [B]; arithmetic shown);
- **[V] to-verify** (believed theorem; exact hypotheses must be checked before load-bearing

## 1. Exponent parameters

For a putative first singular time `T*`, `τ = T* − t`, an axisymmetric candidate with
singular structure at distance `R ~ τ^ρ` from the axis (ring; the on-axis blob is the merged
case `ρ = α`), inner scale `ℓ ~ τ^α` (`α ≥ ρ`, thickness ≤ radius), and sup amplitude
`‖u(t)‖_∞ ~ τ^{−γ}`. Core volume: ring `V ~ R ℓ² ~ τ^{ρ+2α}`; blob `V ~ τ^{3α}`.

## 2. Hard inputs

- **[H1]** `γ ≥ 1/2` (Leray: `‖u(t)‖_∞ ≥ c ν^{1/2} τ^{−1/2}`).
- **[H2]** `γ = 1/2` with bounded prefactor is dead for axisymmetric finite-energy solutions
  (CSTY IMRN 2008 / Comm. PDE 2009; KNSS Acta Math. 2009): **Type II required**,
  `√τ ‖u‖_∞ → ∞`.
- **[H3]** `sup_t ‖u(t)‖_{L²}² ≤ 2E₀` (energy inequality).
- **[H4]** `ν ∫₀^{T*} ‖∇u‖_{L²}² dt ≤ E₀` (dissipation budget).
- **[H5]** `‖∇u(t)‖_{L²} ≥ c ν^{3/4} τ^{−1/4}` (H¹ local-existence lower bound).
- **[H6]** `‖u(t)‖_{L³} → ∞` as `t → T*` (Escauriaza–Seregin–Šverák 2003; limit form
  Seregin 2012). Useful global consequence with [H3]:
  `‖u‖_{L³}³ ≤ ‖u‖_∞ ‖u‖_{L²}²`, so ESŠ + energy re-derives `‖u‖_∞ → ∞`.
- **[H7]** `|u_θ(r,z,t)| ≤ G₀ / r` with `G₀ = ‖r u_θ(·,0)‖_∞` (swirl maximum principle).
- **[H8]** every point `x₀ ≠ 0` is regular at time `T*` (axisymmetric partial regularity:
  singular points lie on the axis; for the finite-energy axisymmetric class the singular set
  at `T*` is contained in the axis and, with CKN, is at most a single point at the origin
  under the present scaling ansatz), and CKN ε-regularity near a regular point gives the
  scale-invariant bound `|u| ≤ C/d` on the parabolic cylinder `Q_{d/2}(x₀, T*)`,
  `d = |x₀|`.
- **[V1]** spatial scale-invariant exclusion family: axisymmetric suitable solutions with
  `|u| ≤ C/r` are regular (KNSS-type Liouville). Used only for interpretive notes below.
- **[V2]** slightly-supercritical refinements near the Type I boundary (Lei–Zhang
  criticality family; recent Type II notes, e.g. arXiv:2402.13229) — they pressure the
  `γ → 1/2⁺` edge; exact statements to be tabulated before load-bearing use.

## 3. Bookkeeping constraints for the core region

- **[B1]** energy: `A²V ≲ E₀` → `ρ + 2α ≥ 2γ` (blob: `3α ≥ 2γ`).
- **[B2]** dissipation: core enstrophy `~ (A/ℓ)² V = τ^{ρ−2γ}` must be time-integrable →
  `2γ − ρ < 1` (blob: `2γ − α < 1`).
- **[B3]** if the core carries the ESŠ divergence: `A³V → ∞` → `ρ + 2α < 3γ`
  (blob: `α < γ`).

## 4. Derived cuts

- **[D1] — WITHDRAWN 2026-08-19.** The original argument ("sub-parabolic ring collapse
  `ρ < 1/2` is dead via CKN parabolic cylinders") contained an unsound step: ε-regularity
  at a regular point does not supply a scale-invariant `|u| ≤ C/d` bound with a uniform
  constant at the visited scale. See
  [`D1_ADVERSARIAL_AUDIT_2026-08-19.md`](D1_ADVERSARIAL_AUDIT_2026-08-19.md). Replacement:
  **[D1′] (conditional)** — under the transport hypothesis (structure advected by the flow
  plus viscous spreading), `ρ ≥ min(1−γ, 1/2)`. The on-axis blob window is unaffected
  (a non-translating core); the ring corridor constraint weakens from `ρ ≥ 1/2` to the
  conditional [D1′] form.
- **[D2] A swirl-dominated core cannot carry the critical-norm divergence.**
  If the sup is carried by `u_θ` at radius `R ~ τ^ρ`, [H7] gives `γ ≤ ρ`. Then [B3] would
  need `ρ + 2α < 3γ ≤ 3ρ`, i.e. `α < ρ`, contradicting `α ≥ ρ`. Hence a swirl-dominated
  scenario requires a **separate mesoscale region** with diverging amplitude to carry
  `L³ → ∞` (it must have diverging amplitude by [H6]+[H3]) — a ≥ 3-region structure.
- **[D3] Meridionally-dominated on-axis blob window.**
  With `ρ = α` and the core carrying `L³`:
  `γ ∈ (1/2, 1)` and `max(2γ/3, 2γ−1) ≤ α < γ` (lower envelope `2γ/3` for
  `γ ≤ 3/4`, `2γ−1` for `γ ≥ 3/4`). The window **closes at `γ = 1`** (`2γ−1 → γ`).
  Interpretive note [V1]: in this window `u·r ~ τ^{α−γ} → ∞` at the core, so the
  `|u| ≤ C/r` criterion is violated at the core, as a genuine singularity requires.
  Structural razor (qualitative, not a kill): [H7] makes the core swirl fraction
  `≤ τ^{γ−α} → 0` — the surviving blob is asymptotically swirl-poor, in tension with the
  swirl-driven amplification mechanism underlying all current axisymmetric scenarios; while
  exactly swirl-free axisymmetric NS is globally regular (Ukhovskii–Yudovich /
  Ladyzhenskaya), asymptotically-small swirl is *not* covered by that theorem.
- **[D4] Meridionally-dominated ring with core-carried `L³` also closes at `γ = 1`.**
  `min(ρ + 2α) = 3ρ > 3(2γ−1)` under [B2], and [B3] needs `ρ + 2α < 3γ`; these are
  compatible only if `6γ − 3 < 3γ`, i.e. `γ < 1`.
- **[D5] Swirl-dominated ≥3-region corridor.** For `γ ≤ ρ ≤ α` with a mesoscale carrying
  `L³` and the outer region carrying energy, soft constraints alone leave a corridor at any
  `γ` (with `ρ > 2γ − 1` forcing hyper-fast ring collapse for large `γ`). The corridor is
  not empty on power counting, but each extra decade of `γ` stacks structural demands
  (three active regions with coupled exponents; the `|u| ≤ C/r` violation [V1] must occur at
  the mesoscale, not the core). Empirical echo: the inviscid two-scale scenario already
  destabilized into a three-scale structure without settling.

## 5. The map

Surviving asymptotics on current knowledge:

1. **Primary window (core-carried `L³`, blob or ring):**
   `1/2 < γ < 1`, `max(2γ/3, 2γ−1) ≤ α < γ` (blob), the analogous `(γ, ρ, α)` slab for
   rings — a nonempty open region. **Axisymmetric Type II is not excluded by current
   arithmetic.**
2. **Baroque corridor:** swirl-dominated ≥ 3-region scenarios, unconstrained in `γ` by soft
   counting but with mounting structural requirements.

Both published Hou geometries lie **outside** the surviving region: the one-scale candidate
sits on the dead `γ = 1/2` boundary [H2]; the two-scale traveling wave, as published, lives
on Clay-inadmissible equations and dies under standard viscosity (see the two-scale gate
document), and its swirl-dominated ring shape would in any case require the ≥3-region
structure of [D2] that it does not have.
